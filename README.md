# Java Backend API - MongoDB & Docker

## 📌 Sobre o Projeto
API RESTful desenvolvida em **Java** com **Spring Boot**, focada no gerenciamento de dados utilizando o banco de dados NoSQL **MongoDB** e conteinerização do ambiente com **Docker**.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java 17
- **Framework:** Spring Boot (Spring Web, Spring Data MongoDB)
- **Banco de Dados:** MongoDB
- **DevOps:** Docker e Docker Compose
- **Arquitetura & Documentação:** Software Design Document (SDD) / Padrão REST
